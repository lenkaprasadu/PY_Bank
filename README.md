# PY_Bank
# PyBank - Simple Python Banking System

PyBank is a simple command-line banking application built using Python.  
This project helps beginners understand Python fundamentals like:

- Functions
- Loops
- Conditional statements
- Lists
- Global variables
- User input handling

---

# Features

✅ Deposit money (supports decimal amounts)  
✅ Withdraw money  
✅ Prevent withdrawal beyond available balance  
✅ Check current account balance  
✅ View transaction history  
✅ Count total deposits and withdrawals  
✅ Menu-driven interface  
✅ Exit option
